# EirasAD-Infraestrutura-Android


# Contexto e Objetivo

Este projeto apresenta como o desenvolvimento de sistemas pode transformar problemas reais em soluções úteis para as pessoas.

O estudo utiliza fontes selecionadas no NotebookLM e o projeto acadêmico EirasAD como referência prática, buscando compreender como a tecnologia pode ser utilizada para melhorar processos e facilitar a rotina das pessoas.

## Objetivo

Compreender como identificar necessidades reais, transformá-las em soluções tecnológicas e avaliar se essas soluções realmente geram benefícios.






# Tema

**Desenvolvimento de sistemas como ferramenta para transformar problemas reais em soluções úteis para as pessoas.**

A tecnologia é utilizada como meio para compreender necessidades, melhorar processos e criar soluções que gerem valor para as pessoas.

# Engenharia de Prompts e Cicatrizes

Durante o estudo no NotebookLM, foram realizados testes e ajustes nos prompts para melhorar a qualidade das respostas.

## Evolução dos Prompts

- **Prompt 1:** resposta ampla demais.
- **Prompt 2:** resposta mais organizada e objetiva.
- **Prompt 3:** conseguiu relacionar teoria e prática, mas apresentou excesso de informações.
- **Prompt 4:** gerou uma definição curta, simples e adequada ao objetivo.

### Principal aprendizado

Um bom prompt precisa deixar claro o objetivo, o nível de detalhe e a linguagem desejada.

#### Prompt aprovado

> Com base nas fontes deste caderno e no projeto EirasAD, defina em poucas palavras como o desenvolvimento de sistemas pode transformar um problema real em uma solução útil para as pessoas. Use linguagem simples, direta e fácil de entender. Evite termos técnicos desnecessários, explicações longas e exemplos secundários. A definição deve ser compreendida por qualquer pessoa, mesmo sem conhecimento de tecnologia.





# Miniguia de Estudo

## Como transformar um problema em uma solução

1. **Identificar o problema** — entender o que precisa ser resolvido.
2. **Compreender as pessoas** — conhecer as necessidades de quem será afetado.
3. **Criar a solução** — transformar a necessidade em uma solução prática.
4. **Melhorar o processo** — tornar as atividades mais simples e eficientes.
5. **Avaliar os resultados** — verificar se a solução trouxe melhorias.

### Glossário

**Design Thinking**  
Abordagem para encontrar soluções considerando as necessidades das pessoas.

**User-Centered Design (UCD)**  
Desenvolvimento centrado nas necessidades e na experiência das pessoas.

**Prototipagem**  
Criação de uma versão inicial de uma solução para testar uma ideia.

**Validação**  
Verificação se a solução atende à necessidade identificada.

**Melhoria contínua**  
Processo de avaliar e ajustar uma solução continuamente.

# Aplicação Prática — EirasAD

O EirasAD demonstra como um problema do cotidiano pode ser transformado em uma oportunidade para aplicar tecnologia na busca de uma solução.

**Problema real → necessidade → solução tecnológica → melhoria → resultado**

O projeto acadêmico EirasAD foi utilizado como referência prática para relacionar os conceitos estudados com o desenvolvimento de sistemas.



# Conclusão

O estudo mostrou que o desenvolvimento de sistemas pode começar pela compreensão de um problema real e das necessidades das pessoas.

A tecnologia entra como ferramenta para criar soluções, melhorar processos e gerar benefícios reais.

O principal aprendizado foi perceber que um bom resultado depende não apenas da tecnologia, mas também de compreender o problema, fazer boas perguntas e avaliar as respostas.
